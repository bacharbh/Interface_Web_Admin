🚀 COMMENT DÉMARRER

1. VÉRIFIER L'ENVIRONNEMENT:
   → .env.local doit avoir REACT_APP_ANTHROPIC_KEY

2. DÉMARRER LE SERVEUR:
   $ npm run dev
   → http://localhost:5173

3. TESTER LA SÉLECTION:
   → Allez à http://localhost:5173/animals
   → Cochez 2-4 animaux
   → Footer sticky apparaît
   → Cliquez "Comparer ↗"

4. EXPLORER LA COMPARAISON:
   → Page /compare charge
   → Explorez tous les contrôles
   → Changez métrique/période
   → Lisez analyse IA

🐛 TROUBLESHOOTING RAPIDE

Problème: "Cannot find module"
Solution: Vérifier les paths imports dans CompareView.tsx

Problème: Graphique ne charge pas
Solution: npm list chart.js react-chartjs-2

Problème: IA analysis échoue
Solution: Vérifier REACT_APP_ANTHROPIC_KEY dans .env.local

Problème: Checkboxes ne s'affichent pas
Solution: Vérifier Animals.jsx a bien la nouvelle colonne
